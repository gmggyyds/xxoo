# xxoo — 吸星大法

把外面的东西**化成自己的**，不是收藏起来。

北冥神功和吸星大法的差别是**化不化得掉**——吸进来化不掉的会互相冲撞、走火入魔。装了一堆 skill 不用、看完视频点个赞，就是吸而不化。
**本 skill 的终点不是「我读懂了」，是「我手上多了一张只有我有的图 ＋ 一份还缺什么的清单」。** 没这两样产出，这一轮就是白吸。

**与相邻 skill 的分工**
- `the-great-me`：把**我自己**的经验变成 AI 能用的（向内）。本 skill 向外取，两者是一对。
- **选型类 skill**（判断要不要装）：那个回答「装/不装」，本 skill 回答「已经决定学了，怎么化」。**先选型，再吸。**
- **公司/品牌调研类 skill**：那些拆的是一个**组织**，本 skill 拆的是**一份方法、一份材料**。

原型案例：2026-09-11 实跑 `nexscope-ai/Amazon-Skills` → `amazon-listing-optimization`（428 行 / 655★）。下文所有 📌 实测数字都出自那次实跑。

## Phase 0 · 取材（按输入类型分诊）

| 输入 | 怎么取 | 坑 |
|---|---|---|
| GitHub 仓 / skill | 先 `ls` 看目录结构，再读正文文件 | **别拿 README 当行为**——README 写的是意图，正文/代码才是行为（同族坑已记录多次）|
| 文章 / 网页 | WebFetch | 付费墙/登录墙取不到就**写"取不到"**，禁止靠标题猜内容 |
| 视频（YouTube/B站/本地）| `yt-dlp` 取音轨 → `ffmpeg` 转码 → `whisper` 转写 | whisper 有**幻觉循环**：长视频分段跑，看到整段重复就重转（lesson 2026-08-15）|
| PDF / 文档 | 直接读 | 扫描件先 OCR；超长的先看目录再定读哪几章 |

**取材硬规则**：读不到的部分**注明缺失，不要猜**。同时记下**来源名称 + 地址 + 版本/commit + 取材日期**——Phase 4 标注「每处改动来自哪边」时要用，而且开源仓会变。

**挑什么值得吸**（四判据，缺一个就换一个 → `references/find-and-pick.md`）：
star > 100 ／ 三个月内有更新 ／ 目录能对上你的环节 ／ 单份 200–600 行。

## Phase 1 · 萃取：画成流程图

**只模拟梳理，不要真的执行**（别人的仓可能带脚本）。把每个环节画成业务人员看得懂的流程图，包含判断、循环、输入与产出；多个模块之间怎么配合也一并画出来。

画图走 **`fireworks-tech-graph`**（全局铁律；PNG 导出后必须 Read 回来做视觉复查，报 `visual_review: passed`）。要留在 md 里可编辑的用 mermaid——对方没有绘图工具时，mermaid 贴进飞书文档会自动转成可编辑白板（`references/no-drawing-tool.md`）。

**验收**
- ✅ 步骤数**比原文小标题数少** —— 少才说明在萃取，不是在复述目录
- ✅ 藏在正文里的**判断**被拎出来了（什么时候回退、什么时候先做哪一步）
- ❌ 拿到的是章节目录的翻译 → 重画：「不要复述章节，画执行路径」

> 📌 实测：428 行的文档，真正的流程只有 **11 步**，其余全是模板和输出样板。
> **最有价值的不是步骤，是藏在文字里的判断**（"脚本抓不全就回退网页抓取"、"给了竞品 ASIN 要先抓竞品"）——光看目录看不见，画流程图才会被逼着写出来。

## Phase 2 · 🔴 验证：这张图在我的生意里成立吗（硬门禁）

**这一步不能交给 AI 代劳，AI 只能起个头。** 上一步 AI 几秒钟就干完，这一步得业务的人自己判——**这一步才长本事**。

逐环填四列表（模板与提示词 `references/verify-table.md`）：

| 环节 | 在我这成不成立 | 它假设了什么我并不具备的 | 我有什么它没考虑到的 | 沿用/删/改 |

对照哪些环节：`references/business-rings.md`（五环 ＋ 培训/内容/供应链/组织四条线）。

**硬验收（两条都不满足＝没真跑）**
- ✅ 「删」＋「改」**不为零** —— 全部"沿用"说明没拿业务去对，是在读文档
- ✅ 第三列「我有什么它没考虑到的」**每一环都填得出东西** —— 这列填不出来的人，是在读文档

> 📌 实测：**沿用 3 ／ 改 8 ／ 删 0**（11 环）。它的八维度评分里**有两维对品牌模式是反的**——价格项惩罚溢价（比同类中国卖家贵要扣分，而那正是策略）、评论项只数星级不看内容（4.8 星 5000 条全在夸"便宜"，打分赢过 4.3 星 200 条全在说"终于睡整觉了"）；还完全没有人群阶段匹配度／复购钩子／用户原话覆盖率。
> **这不是它写得差**——它每条规则放在铺货/精品模式下都成立。**它服务的是"卖货"，我们做的是"围绕一群人"。抄的不是流程，是流程背后那门生意的假设。**

> 📌 反常识：**要改的全在「输入」层，不在「怎么干活」层**。词从哪来、怎么排序、收什么属性、缺口怎么定义——全挤在最前面几步；怎么写、怎么做前后对比这些**产出层**的东西基本能整段沿用。
> **抄一个东西抄错的地方，通常不在它怎么干活，在它认为该拿什么进来。**

## Phase 3 · 自画：基于你的真实上下文画一版

**AI 执笔，你校正。** 和 Phase 2 的分工不一样，别混：

```
Phase 2 验证   下判断      AI 没资格，只能起头
Phase 3 自画   把已有的画出来   AI 更快更全，你负责校正
```

输入三层，能拿到几层用几层：

| 层 | 来源 | 说明 |
|---|---|---|
| ① 画像 | `the-great-me` 的自我画像 | 你是谁、优势、资源、缺哪种杠杆。没装就跳过这层 |
| ② 环节清单 | `references/business-rings.md` | 你的业务环节。**空着也行**，第 ③ 层能帮你把它起草出来 |
| ③ **真实业务产物** | 你本机实际在跑的东西 | **最硬的一层** |

第 ③ 层是关键，也是这一步真正的价值所在：

> 前两层是你**嘴上说的**自己，第三层是你**实际在做的**自己。
> **两者对不上的地方，本身就是产出**——比如你以为自己在做品牌，
> 机器上跑的全是铺货的活。这种事你自己想不出来，只有让它去读才会撞见。

### 读到什么程度（三档，默认「中」）

```
浅   只读你点名的文件                            你说读哪个就读哪个
中   扫一个目录：文档、配置、脚本；不碰数据        ← 默认
深   连数据结构、历史对话一起读，AI 自己找相关的    最有用，也最需要你信任它
```

### 🔴 边界（读之前先声明，别等人问）

- **只读不传。** 全部留在本机，不上传、不写进任何会离开这台机器的地方。
- **一律跳过**：`.env` / 密钥 / token / 客户名单 / 个人隐私。碰到就说明跳过了什么。
- **不确定该不该读的，先问，不要自己决定。**
- 产出里引用真实业务内容时，**只引用判断和结构，不搬原始数据**。

> ⚠️ **顺序仍然不能反**：Phase 3 要在 Phase 2 之后，而且**不参考 Phase 1 的萃取结果**来画。
> 先看别人再画自己，画出来的一定是它的变体——这一条不因为换成 AI 执笔就失效，
> 反而更要守：AI 手里刚拿过那份萃取图，不明说它一定会顺着画。

## Phase 4 · 合一

两份合成一版：可借鉴的吸收进来、不适合的剔除、独有的保留。

**验收**
- ✅ 每一处改动说得清**来自哪边**和**为什么**
- ✅ 最终那张图里**至少有一处是别人方案里没有、只有你有的**
- ✅ 结尾有一份**「还缺什么」清单** —— 缺口写不出来，说明这张图还停在纸上

## Phase 5 · 归档（否则下次还得重吸一遍）

落进**你已有的知识库目录**（**不要为它新建一个库**）。一次一目录：

```
<日期>_<对象名>/
  00_源材料指针.md      地址 + 版本/commit + 取材日期（开源仓会变，数字会过期）
  01_萃取_流程图.md      ＋ img/*.svg|png
  02_验证表.md           ← 最有价值的一份
  03_我的版本与合一.md    ＋「还缺什么」清单
```

写完更新知识库索引——不进索引的东西等于没归档。

## 硬规则

- **只读不跑** —— Phase 1 模拟梳理 ≠ 执行。
- **README 不是行为** —— 与正文/代码冲突时以后者为准。
- **数字带日期** —— star 数、行数、目录规模全会变；引用必标拉取日期，上台/对外交付前重新拉一次。
- **禁止跳过 Phase 2 直奔 Phase 4** —— 跳过就退化成"把别人的文档翻译了一遍"，就是吸而不化。
- **不许奉承** —— 给 AI 的提示里必须带「不适合就直接说不适合，不要奉承我」。那两维是反的，就是这么发现的。

## 时间预算（实测：材料齐备、全程不中断）

| Phase | 自己单跑 | 带人演示 |
|---|---|---|
| 0 取材/挑 | 3 分钟 | 3 分钟 |
| 1 萃取 | 12 分钟 | 8 分钟（AI 几秒出图，**看着做学不到东西**）|
| 2 验证 | **20 分钟，最费脑** | 演示 12 分钟 ＋ 对方自己做 15 分钟 |
| 3 自画 | 8 分钟 | 对方 10 分钟 |
| 4 合一 | 10 分钟 | 课后/晚自习 |
| **合计** | **约 50 分钟** | 必须拆开走，一口气跑不完 |
