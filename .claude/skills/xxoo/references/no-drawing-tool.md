# 对方没有画图工具时，「画成流程图」怎么落地

> 🔴 这是实跑核对时发现的落差：**我用的是自己那套画图 skill，出的是 SVG/PNG；对方没有。**
> 他们让 AI"画流程图"，AI 只会给一段代码，终端里看不到图。
> 零门槛的路：**让 AI 出 mermaid，粘进飞书文档，飞书自动转成可编辑画板。**

## 完整路径（不用装任何东西）

**第一步：明确要 mermaid，不要笼统说"画流程图"**
```plaintext
把刚才萃取的流程，用 mermaid flowchart 语法输出，直接给我代码块。
判断用菱形，步骤用方框，每个框里写「编号 + 一句话」，超过五个字的说明放第二行。
不要输出解释，只给代码。
```

**第二步：整段代码（含 ```mermaid 围栏）粘进飞书文档 → 自动变成画板**

**第三步：在飞书画板里直接改** —— Phase 2 标"沿用/删/改"可以直接标在画板上。

## 备选路径

```
mermaid.live    粘代码即出图，可导出 PNG／SVG
VS Code         装 Markdown Preview Mermaid 插件
GitHub / Typora 原生支持 mermaid 渲染
```

## ⚠️ 一处至今没验证到

飞书**接受 mermaid 并转成画板块**这件事已确认（回读到 `<whiteboard>` 块）。
但画板缩略图下载接口返回 404，**没能在终端里看到渲染出来的样子**。
**对外用之前请自己打开文档确认画板显示正常** —— 排版乱了就改用 mermaid.live。

## 自己跑的时候

走 `fireworks-tech-graph`（全局铁律）：
- 默认 Style 1；对外/给同事看用 Style 6（Claude 暖米色）或 4（Notion Clean）
- **中文图必须把 CJK 字体放 `font-family` 第一位**，否则 cairosvg 出图汉字全变 □
- 禁用 `→ ✓ ✗ ｜` 等符号（同样变 □）
- **PNG 导出后必须 Read 回来做视觉复查**，报 `visual_review: passed`
  （validate 只验语法，验不出箭头穿组件/箭头方向反了——原型案例第一轮就抓到这两处）
