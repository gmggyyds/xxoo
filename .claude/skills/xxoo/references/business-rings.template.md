## 不想手填？让它替你起草

这张表最大的问题是**空着的时候没人愿意填**。所以别硬填——
让 AI 去读你本机真实在跑的东西，先起草一版，你只负责改：

```
用吸星大法的 Phase 3 帮我起草业务环节清单：
扫一下 <你的工作目录>，看我实际在跑什么，
按你看到的东西把环节和「我独有的」两列填出来，
拿不准的标问号，别编。
```

它读出来的东西可能和你以为的不一样——**那个差异本身就是最值钱的产出**。
（读取范围和边界见 SKILL.md 的 Phase 3，默认只扫文档配置、不碰数据。）

## 两列分别怎么填

**「现在怎么干」** —— 写不出完整流程也行，能说清就行。
这一列决定 Phase 2 第一问（这一环在我这成不成立）答得准不准。

**「我独有的」** —— 最关键的一列。数据源、渠道、关系、判断标准、别人拿不到的东西。
Phase 2 第三列「我有什么它没考虑到的」**直接从这一列取**。
取不到就说明这一环的资产盘点是空的——**那本身就是一个发现。**

## 怎么用

1. Phase 2 开始前，先定**这次吸的东西落在哪一环**（跨环就每环各填一行）。
2. 跑完如果发现右列该补，**当场补进来**——这份清单是活的。

## ⚠️ 别把这份表放进任何会离开你机器的地方

填好之后它会含有你的数据规模、渠道、供应商、组织缺口。
对外分享 Phase 2 的产出时，只分享**判定和方法**，不要贴这张表。
