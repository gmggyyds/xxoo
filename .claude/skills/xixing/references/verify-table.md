# Phase 2 · 验证表（模板 + 提示词 + 硬验收）

> **整个 skill 里唯一不能交给 AI 的一步。** AI 只能起头，判断得业务的人自己做。
> 上一步 AI 几秒钟就干完了，这一步得想 20 分钟——**这 20 分钟才是本事**。

## 表格模板

| 环节 | 在我这成不成立 | 它假设了什么我并不具备的 | 我有什么它没考虑到的 | 判定 |
|---|---|---|---|---|
| （逐环一行，用萃取图里的编号）| ✅ / 部分 / ❌ | | | 沿用 / 删 / 🔧改 |

**末行必须有汇总**：`沿用 N ／ 改 N ／ 删 N`

## 起头用的提示词

```plaintext
这是刚才萃取出来的流程图。现在拿我的业务去检验它：
我做的是[填模式]，我这一环现在是这么干的：[填现状，没有就说没有]。
逐环回答三件事：
  一、这一环在我的业务里成不成立？为什么？
  二、它假设了什么我并不具备的条件（团队、数据、工具、预算）？
  三、我有什么它没考虑到的东西（我的用户原话、我的供应链、我的判断标准）？
成立的标"沿用"，不成立的标"删"，需要改的标"改"并说明改成什么。
不要奉承我，不适合就直接说不适合。
```

**拿到 AI 的初稿之后，第三列必须自己重写一遍。** AI 不知道你有什么——它只能从你那两句话里推，推出来的都是泛泛之词。

## 硬验收（两条都不满足＝这一轮没真跑）

```
✅ 「删」＋「改」不为零
   全部"沿用"＝没拿业务去对，是在读文档
✅ 第三列每一环都填得出东西
   这列填不出来的人，就是没在用自己的生意对
```

## 单拎出来看「评分/打分」类环节

**凡是对方给了一套评分维度或权重的，一定单独拆开逐维看。** 评分维度是一门生意的价值观的浓缩，最容易整套照搬，也最容易搬错——它不会报错，只会让你一直往错的方向优化。

逐维问三句：
1. 这一维在我的模式下**方向对不对**（会不会奖励了我要罚的、罚了我要奖的）
2. 它量的是**数量**还是**内容**
3. 我最看重的那几件事，**在不在这张表里**

## 📌 实测样例（2026-09-11，`amazon-listing-optimization` 428 行 / 655★）

**判定汇总：沿用 3 ／ 改 8 ／ 删 0**（11 环）

八维度评分 `标题15｜五点15｜图片15｜A+10｜描述10｜价格10｜评论15｜SEO覆盖10 = 100`：

| | 结果 |
|---|---|
| 五维成立 | 标题/五点/图片/A+/描述——Amazon 页面的客观构成，谁做都得看 |
| **两维方向是反的** | **价格 /10**：比同类中国卖家贵要扣分，而那正是策略<br>**评论 /15**：只数星级和条数不看内容——4.8 星 5000 条全在夸"便宜"，打分赢过 4.3 星 200 条全在说"终于睡整觉了" |
| **三项完全没有** | 人群与阶段匹配度 ／ 复购钩子 ／ 用户原话覆盖率 |

> **这不是它写得差**——它每一条规则放在铺货/精品模式下都成立。
> **它服务的是"卖货"，我们做的是"围绕一群人"。抄的不是流程，是流程背后那门生意的假设。**

**反常识发现**：要改的 8 处**全部挤在最前面的「输入」层**（词从哪来、怎么排序、收什么属性、缺口怎么定义），
而"怎么写文案""怎么做前后对比"这些**产出层**的东西基本能整段沿用。

> **抄错的地方，通常不在它怎么干活，在它认为该拿什么进来。**
